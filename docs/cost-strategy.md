# Cursor versus ChatGPT cost and usage

| Work | Use | Do not use |
| --- | --- | --- |
| Repo edits, tests, schema validation, deterministic render/QA | Cursor Cloud Agent | ChatGPT as a hidden coder |
| Policy interpretation against Drive | ChatGPT | Cursor inventing policy |
| Independent social/legal QA pass | ChatGPT | Same agent that produced the asset |
| Repeatable bounded implementation | Cursor | Open-ended strategy essays in the repo |
| Browser/operator clicks | Grok Bot when authorised | Cursor pretending to be logged-in |

Keep Cursor tasks short and mechanical. Keep ChatGPT on ownership, policy, and PASS/FAIL. Do not stream the knowledge base into GitHub to save a later prompt.
